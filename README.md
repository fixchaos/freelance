# Freelance

Maqueta frontend de una landing page para servicios profesionales, desarrollada con **HTML5 y CSS3**.

## 🎨 Sobre el proyecto

**Freelance** es un ejercicio de maquetación web centrado en reproducir la estructura visual de una landing page profesional a partir de HTML y CSS.

El proyecto trabaja la distribución de contenidos, tipografía, espaciado, colores y composición visual, utilizando una estructura sencilla y adaptable a diferentes tamaños de pantalla.

## 🧱 Maquetación

El proyecto incluye una estructura compuesta por:

* Encabezado y navegación.
* Sección principal con imagen destacada.
* Secciones de contenido.
* Presentación de servicios.
* Sección de contacto.
* Pie de página.

## 🛠️ Tecnologías

* HTML5
* CSS3
* Normalize.css
* Google Fonts
* Responsive Design

## 📐 Conceptos practicados

* Estructuración de contenido con HTML5.
* Maquetación mediante CSS.
* Diseño responsive.
* Uso de tipografías externas.
* Organización de estilos en archivos independientes.
* Adaptación de la interfaz a diferentes resoluciones.

## 🎯 Objetivo

Practicar la construcción de una interfaz frontend estática, trabajando desde la estructura HTML hasta la composición visual mediante CSS.

Proyecto desarrollado con fines educativos y de portafolio.
